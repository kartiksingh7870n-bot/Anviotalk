┌─────────────────────────────────────────────────────┐
│  PANEL BAND KARNE KE LIYE                           │
└─────────────────────────────────────────────────────┘

  • Admin window me upar-right ✕ (cross) dabao
  • Phir black server window bhi band kar do

┌─────────────────────────────────────────────────────┐
│  PANEL ME KYA-KYA HAI                               │
└─────────────────────────────────────────────────────┘

  📊 DASHBOARD     → Poore app ka summary (users, posts,
                     reports, paisa) — sab ek nazar me

  👥 USERS         → Saare users ki list
                     • Kisi ko block karna hai → "Suspend"
                     • Hamesha ke liye block → "Ban"
                     • Galti se block ho gaya → "Reactivate"

  🚩 REPORTS       → Jo log ne report kiya
                     • Report galat hai → "Dismiss"
                     • Reported POST hatana hai → "Delete Post"
                     • Reported USER ko hatana hai → "Suspend User"

  🖼️ POSTS/STORIES → App ki saari posts photo ke saath
                     • Koi ganda post dikhe → "Delete" button

  💰 PAYOUTS       → Creators ke paise nikalne ke requests
                     • Paisa bhejne ke baad UTR daalo → "Mark Paid"
                     • Request galat hai → "Decline"

  📈 MONETIZATION  → Kis creator ke kitne views/ paisa bana
